# ENDLESS FLIGHT

宇宙を自機が自動で延々と飛び続けるのを眺めるアプリ。そのまま MP4 に書き出せる。
[ENDLESS DUNGEON](https://haristweet.github.io/endless-dungeon/) の姉妹作で、書き出し・音・歌詞の仕組みは共通。
`index.html` と同梱の `mp4-muxer.js`・`opus-decoder.min.js` だけで動く（ビルド不要）。

## できること

- 景色4種を「区域」として順に巡る（選んだものだけ）
  - 星の海：星・小惑星・輪のある惑星
  - 戦艦の溝：巨大な要塞の表面の溝を低く飛ぶ
  - 地平線：市松模様の地面と柱の間を縫う
  - トンネル：うねる筒の中、光る輪をくぐる
  - 区域は 30秒 / 1分 / 2分 ごとに暗転して切り替わり、「区域 2　戦艦の溝」と出る
- 描き方：ポリゴン（面塗り）/ 線画（隠れ線処理つき。線の色は景色ごと・白・緑・琥珀・水色・桃）
- 視点：後ろから機体を見る / 操縦席
- 画面の飾り（あり/なし）
  - あり：計器（速度・シールド・エネルギー・距離・区域）、レーダー（航路と周りの物）、通信欄
- 画素の粗さ、速さ3段階、航路の番号（シード。同じ番号なら同じ航路）
- MP4書き出し
  - 大きさ：640×480〜1920×1080
  - 長さ：「3:19」のように分:秒で指定
  - 30 / 60コマ/秒
  - 音：MP3・M4A・WAV などを入れると音付き（長さは曲に合わせる）
  - 歌詞：曲に入っている歌詞か .lrc / .srt / .vtt を、通信欄（飾りなしなら字幕）に流す

## しくみのメモ

- **航路**：正弦波の和で x・y が z（奥行き）に沿ってうねる。機体は航路の上を一定速度で進み、曲がり具合で機体を傾ける。
- **景色**：奥行き60ごとの区切りを、番号・区域・区切りの番号から決まる乱数でその場で組み立てる。物は航路から離して置く。
- **描画**：WebGL2。
  - 全部を三角形にして、各頂点に重心座標を持たせ、辺の近くだけ線にする（四角形の対角線は隠す）。
  - 線画では面を黒く塗るので、奥の線が手前の物で正しく隠れる。
  - ポリゴンでは面の向きから陰影を付けて、縁を少し暗くする。
  - 空は全画面の一枚で、視線の向きから地平線の色の段階を出す。遠くの星は向きだけの点。
- **書き出し・音・歌詞**：ENDLESS DUNGEON と同じ（WebCodecs＋mp4-muxer、Safari の AAC の癖への対処、Opus 入り .m4a の自前解読、MP4 の字幕トラックから歌詞）。
- ローカル確認：`python3 -m http.server 8800`
