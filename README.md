# ENDLESS FLIGHT

宇宙を自機が自動で延々と飛び続けるのを眺めるアプリ。そのまま MP4 に書き出せる。
[ENDLESS DUNGEON](https://haristweet.github.io/endless-dungeon/) の姉妹作で、書き出し・音・歌詞の仕組みは共通。
`index.html` と同梱の `mp4-muxer.js`・`opus-decoder.min.js` だけで動く（ビルド不要）。

## できること

- 景色9種を「区域」として順に巡る（選んだものだけ。宇宙と地上が交互になる順）
  - 星の海：星・小惑星・輪のある惑星
  - 砂漠のピラミッド：砂丘の谷、遠くにピラミッド（ときどき三つ並び）、オベリスク、ヤシ。空に太陽
  - 戦艦の溝：巨大な要塞の表面の溝を低く飛ぶ
  - 大河のジャングル：うねる大河の上を低く、両岸は密林
  - 地平線：市松模様の地面と柱の間を縫う
  - 夜の摩天楼：窓の灯りの帯が並ぶビルの谷間を、光る道路に沿って
  - トンネル：うねる筒の中、光る輪をくぐる
  - 雪の山脈：雪の峰と岩肌の谷、針葉樹
  - 溶岩の大地：暗い岩の大地に光る溶岩の川、火口の光る火山。赤黒い空
  - 区域は 30秒 / 1分 / 2分 ごとに暗転して切り替わり、「区域 2　砂漠のピラミッド」と出る
- 描き方：ポリゴン（面塗り）/ 線画（隠れ線処理つき。線の色は景色ごと・白・緑・琥珀・水色・桃）
- 視点：後ろから機体を見る / 操縦席
- 画面の飾り（あり/なし）
  - あり：計器（速度・シールド・エネルギー・距離・区域）、レーダー（航路と周りの物）、通信欄
- 画素の粗さ、速さ3段階、航路の番号（シード。同じ番号なら同じ航路）
- MP4書き出し
  - 大きさ：640×480〜1920×1080
  - 長さ：「3:19」のように分:秒で指定
  - 30 / 60コマ/秒
  - 音：MP3・M4A・WAV などを入れると音付き（長さは曲に合わせる）
  - 歌詞：曲に入っている歌詞か .lrc / .srt / .vtt を、通信欄（飾りなしなら字幕）に流す
  - 終わり方：「BAD END にする」にチェックを入れると（曲を入れたときだけ）、曲の終わりに前からミサイルが飛んできて被弾・爆発して終わる。3.6秒前に「WARNING　ミサイル接近」と警報、レーダーに赤い点。被弾は終わりの2.6秒前で、計器が0になり、暗転して「BAD END／通信が 途絶えた」

## しくみのメモ

- **航路**：正弦波の和で x・y が z（奥行き）に沿ってうねる。機体は航路の上を一定速度で進み、曲がり具合で機体を傾ける。
- **景色**：奥行き60ごとの区切りを、番号・区域・区切りの番号から決まる乱数でその場で組み立てる。物は航路から離して置く。
- **地形**（地上の景色）：格子状の起伏を値ノイズで作り、航路のまわりだけ谷になるよう低くする。色は高さ・傾き・ノイズで決める（雪・岩肌・溶岩の川など）。
- **描画**：WebGL2。
  - 全部を三角形にして、各頂点に重心座標を持たせ、辺の近くだけ線にする（四角形の対角線は隠す）。
  - 線画では面を黒く塗るので、奥の線が手前の物で正しく隠れる。
  - ポリゴンでは面の向きから陰影を付けて、縁を少し暗くする。
  - 空は全画面の一枚で、視線の向きから地平線の色の段階と太陽を出す。遠くの星は向きだけの点。
- **書き出し・音・歌詞**：ENDLESS DUNGEON と同じ（WebCodecs＋mp4-muxer、Safari の AAC の癖への対処、Opus 入り .m4a の自前解読、MP4 の字幕トラックから歌詞）。
- **バッドエンド**：`CRASH`（ミサイルが見える秒・被弾の秒・速さ）と `Sim.crash()`。ミサイルは航路に沿ってこちらへ飛ぶ。被弾したら機体は止まり、`blastMesh()` で火の玉（大きくなって暗くなる）と破片（地上では落ちる）を描く。後ろからでは少し引いて、操縦席でははじき出されて回りながら爆発を見る。終わりの8秒前より後には区域を変えない（暗転と重ならないように）。音（警報・風切り・爆発）は `crashSfx()` で作り、書き出しでは曲の上に重ねる。プレビューでは終わって2.5秒で最初から。
- ローカル確認：`python3 -m http.server 8800`
- 絵の確認：サーバーを立てて `node test/shots.mjs 出力.png`（無音の曲を入れて BAD END にし、被弾の前後を景色・視点・描き方を変えて一覧にする）
